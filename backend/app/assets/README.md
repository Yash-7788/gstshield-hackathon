# Bundled report font

NotoSans-Regular.ttf is licensed under the SIL Open Font License; see NotoSans-LICENSE.txt.
Source: https://raw.githubusercontent.com/notofonts/noto-fonts/main/hinted/ttf/NotoSans/NotoSans-Regular.ttf
SHA256: b85c38ecea8a7cfb39c24e395a4007474fa5a4fc864f6ee33309eb4948d232d5

The generator verifies this hash and glyph coverage offline. Unsupported characters fail the
artifact with REPORT_UNSUPPORTED_TEXT instead of silently rendering missing glyphs. This font
covers Latin, Greek and Cyrillic text and the rupee sign; it is not a universal Indic-script font.
There is no runtime font download, remote renderer, or external report service.
